# Репозиторій для лабораторних робіт з дисципліни "Організація і збереження баз даних" 
**Тема:** Кімнатні рослини, сукуленти та флораріуми

---

## Лабораторна робота 1. Дизайн та документування схеми бази даних
* Створено концептуальну схему (нотація Чена) та логічну модель на 5 таблиць (Users, Categories, Products, Orders, Order_Items).
* Схему описано мовою DBML (`lab-work-01/schema.dbml`).
* Налаштовано CI/CD воркфлоу у GitHub Actions для публікації документації.
* Посилання на документацію dbdocs: https://dbdocs.io/steblin.ivan/schema

---

## Лабораторна робота 2. Реалізація фізичної схеми та наповнення бази даних
* Розгорнуто локальну базу даних MySQL та налаштовано підключення через DBeaver.
* У директорію `lab-work-02` додано SQL-скрипти:
  * `1_create_schema.sql` — DDL-скрипт створення структури таблиць, первинних та зовнішніх ключів.
  * `2_populate_data.sql` — DML-скрипт тестового наповнення бази даних.

---

## Лабораторна робота 3. Маніпуляція даними та комплексні запити
* Виконано базові DML-операції модифікації даних (INSERT, UPDATE, DELETE) та вибірки DQL із фільтрацією (WHERE, IN, LIKE) і сортуванням (ORDER BY).
* Реалізовано комплексні аналітичні запити (агрегатні функції, GROUP BY, HAVING, INNER JOIN на 4 таблиці, LEFT JOIN, підзапит та UNION).
* У директорію lab-work-03 додано SQL-скрипти:
  * `lab_3_DML.sql` — скрипт виконання CRUD-операцій.
  * `lab_3_DQL.sql` — скрипт базових запитів вибірки та фільтрації.
  * `lab_3_DQL_extra.sql` — скрипт комплексних аналітичних вибірок підвищеної складності.
