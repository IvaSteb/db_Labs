# Репозиторій для лабораторних робіт з дисципліни "Організація і збереження баз даних" 
**Тема:** Кімнатні рослини, сукуленти та флораріуми

---

## Лабораторна робота 1. Дизайн та документування схеми бази даних
* Створено концептуальну схему (нотація Чена) та логічну модель на 5 таблиць (Users, Categories, Products, Orders, Order_Items).
* Схему описано мовою DBML (`lab-work-1/schema.dbml`).
* Налаштовано CI/CD воркфлоу у GitHub Actions для публікації документації.
* Посилання на документацію dbdocs: https://dbdocs.io/steblin.ivan/schema

---

## Лабораторна робота 2. Реалізація фізичної схеми та наповнення бази даних
* Розгорнуто локальну базу даних MySQL та налаштовано підключення через DBeaver.
* У директорію `lab-work-2` додано SQL-скрипти:
  * `1_create_schema.sql` — DDL-скрипт створення структури таблиць, первинних та зовнішніх ключів.
  * `2_populate_data.sql` — DML-скрипт тестового наповнення бази даних.

---

## Лабораторна робота 3. Маніпуляція даними та комплексні запити
* Виконано базові DML-операції модифікації даних (INSERT, UPDATE, DELETE) та вибірки DQL із фільтрацією (WHERE, IN, LIKE) і сортуванням (ORDER BY).
* Реалізовано комплексні аналітичні запити (агрегатні функції, GROUP BY, HAVING, INNER JOIN на 4 таблиці, LEFT JOIN, підзапит та UNION).
* У директорію `lab-work-3` додано SQL-скрипти:
  * `lab_3_DML.sql` — скрипт виконання CRUD-операцій.
  * `lab_3_DQL.sql` — скрипт базових запитів вибірки та фільтрації.
  * `lab_3_DQL_extra.sql` — скрипт комплексних аналітичних вибірок підвищеної складності.

---

## Лабораторна робота 4. Програмування бази даних: представлення, процедури та тригери
* Створено представлення `v_Detailed_Orders` для формування звітності про замовлення на основі об'єднання 4 таблиць.
* Розроблено збережену процедуру `sp_AddNewProduct` для параметризованого додавання нових товарів у каталог.
* Реалізовано тригер `trg_Products_BeforeUpdate` для автоматичної фіксації дати та часу зміни записів у таблиці товарів.
* У директорію `lab-work-04` додано артефакти:
  * `lab_4_view.sql` — створення та перевірка представлення.
  * `lab_4_procedure.sql` — створення та виклик збереженої процедури.
  * `lab_4_trigger.sql` — створення та демонстрація роботи тригера.
 
 ---

 ## Лабораторна робота 5. Управління транзакціями та оптимізація запитів (індекси)
* Реалізовано базові сценарії управління транзакціями `COMMIT` та `ROLLBACK` для забезпечення цілісності даних при модифікації записів.
* Створено індекси `idx_users_name` та `idx_products_price` для прискорення пошукових запитів.
* Розроблено комплексну атомарну бізнес-транзакцію оформлення замовлення зі списанням залишків зі складу та проведено аналіз планів виконання запитів через `EXPLAIN`.
* У директорію `lab-work-5` додано артефакти:
  * `lab_5_commit.sql` — демонстрація успішної фіксації транзакції.
  * `lab_5_rollback.sql` — демонстрація відкату змін транзакції.
  * `lab_5_index.sql` — створення індексу для таблиці користувачів.
  * `lab_5_complex_transaction.sql` — комплексна бізнес-транзакція оформлення замовлення.
  * `lab_5_explain.sql` — скрипт діагностики запитів через `EXPLAIN` до та після індексації.
  * `4_explain_analysis.md` — текстові результати `EXPLAIN` та аналітичний висновок.
