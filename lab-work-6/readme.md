# Лабораторна робота 6. Управління доступом (DCL) та функції SQL/JSON

SQL-скрипти розмежування прав доступу та формування JSON-структур:
* `lab_6_basic_dcl.sql` — створення користувача `web_client` з правом `SELECT` лише для таблиці `Products`.
* `lab_6_security.sql` — реалізація політики мінімальних привілеїв для облікового запису `app_backend`.
* `lab_6_basic_json.sql` — форматування даних користувача у JSON-об'єкт за допомогою `JSON_OBJECT`.
* `lab_6_complex_json.sql` — вибірка профілю користувача із вкладеним JSON-масивом усіх його замовлень.
